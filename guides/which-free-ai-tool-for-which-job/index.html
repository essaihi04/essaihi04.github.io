Which Free AI Tool for Which Job? The Cheat Sheet

⬇ Download the PDF

Four everyday jobs, one free tool for each. Every fact below was checked on the tool's own page in November 2026. Free plans change often: check the linked page before you rely on a limit.

1. Writing → ChatGPT, Claude or Gemini

  • All three have a free plan.
  • How to use it: paste your rough draft and ask for three versions in different tones (short, friendly, formal). Pick the best lines from each.
  • Sources: ChatGPT pricing · Claude pricing · Gemini plans

2. Research → Perplexity

  • Every answer includes numbered citations that link to the original pages.
  • How to use it: open at least two of the cited pages before you repeat a fact. A chatbot answering from memory can sound sure and still be wrong.
  • Source: How does Perplexity work?

2b. Research in your own files → Gemini Notebook (formerly NotebookLM)

  • Google renamed NotebookLM to Gemini Notebook in July 2026. Same product.
  • Without a paid AI plan: up to 50 sources per notebook (PDFs, docs, links, notes).
  • How to use it: upload your course notes or reports, then ask questions about them.
  • Sources: Google blog · Limits

3. Images → the Gemini app

  • Image generation works without a Google AI plan. Limits depend on demand and are shown in Settings → Usage limits.
  • Source: Gemini Apps limits

4. Code → GitHub Copilot Free

  • $0, no credit card, 2,000 code completions per month, plus limited chat.
  • Source: GitHub Copilot plans

The one mistake to avoid

Using one chatbot for all four jobs. Match the tool to the job: a writer for writing, a cited search for facts, your own files for study, a code assistant for code.

The 30-second version

| Job | Free tool | Why |

|---|---|---|

| Writing | ChatGPT / Claude / Gemini | Free plans, great drafts |

| Research | Perplexity | Numbered sources on every answer |

| Your files | Gemini Notebook | Answers from what you upload (50 sources) |

| Images | Gemini app | No paid plan needed |

| Code | GitHub Copilot Free | 2,000 completions a month, $0 |
