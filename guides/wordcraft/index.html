What it is

WordCraft is a word processor written from scratch in Rust by the ArtCraft team. Per its README it opens and saves .docx, reads and writes .odt, .rtf, .html, .md, .tex and .txt, exports PDF, and has a command-line tool. It passed 15,000 GitHub stars in under three weeks (snapshot of 2026-10-23: 15,733 stars, repo created 2026-10-06).

Install (from the README, requires Rust/cargo)

  1. git clone https://github.com/storytold/wordcraft && cd wordcraft
  2. Desktop app with a sample document: cargo run --release -p wordcraft -- --sample
  3. Command-line tool only: cargo build -p wordcraft-cli (our sandbox build took about 5.5 minutes)

What we really ran (sandbox, 2026-10-27)

  • wordcraft-cli run --template sample --cmd 'select.text={"text":"Membership"}' --cmd format.bold --save out.docx → wrote a 10,648-byte .docx in about 0.1 s
  • wordcraft-cli convert out.docx out.pdf → 47,851-byte PDF in about 3.6 s
  • wordcraft-cli text out.docx → plain text of the document

3 ways to use it

  1. Convert documents between formats from a script: wordcraft-cli convert in.docx out.md
  2. Dump the text of a .docx: wordcraft-cli text file.docx
  3. Inspect a document's structure as JSON: wordcraft-cli inspect file.docx

Honest verdict

It works for what we tried. The build is slow. Check the README for platform installers and the project's roadmap before relying on it.
