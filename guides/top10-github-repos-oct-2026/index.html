Install steps (from each README)

  • DeepSeek Harness: install Node.js, then npx @deepseek-ai/dsh web. In our sandbox the npx launch failed with "dsh: not found" (package version 0.2.1-rc.2 exists on npm). Or from source: pnpm install && pnpm run build && pnpm dsh web.
  • Harness² (we ran this): Linux, Python 3.12, uv. uv venv --python 3.12 .venv, source .venv/bin/activate, uv pip install -e '.[render]', harness2-demo --output runs/demo --k 2. Result for us: 2 tasks completed, 0 failed.
  • Anatomy: npx skills add wheresryan22/anatomy -g, then /anatomy explain how a token bucket rate limiter works, interactive.
  • Ponytail (Claude Code): /plugin marketplace add DietrichGebert/ponytail, then /plugin install ponytail@ponytail.
  • Skills: claude plugin install mattpocock-skills@claude-plugins-official, then run /setup-matt-pocock-skills once per repo.
  • WordCraft: cargo run --release -p wordcraft -- --sample (needs Rust).
  • OpenClaw: the README's main installer pipes a script into the shell. We did not run it. Read the script first, or use the npm package route in the README.
  • DeepInfer, PhotoCraft, SolidCraft: see each README; DeepInfer needs a supported GPU, and the other two are Rust projects (cargo).

3 things to do

  1. Open each README and check the license file before using a repo.
  2. Try the one that fits your stack in a throwaway folder or container.
  3. Check the repo's issues and last commit date before relying on it.

2 mistakes to avoid

  1. Running curl | sh installers without reading them.
  2. Treating a README's benchmark claims as proven: they are the authors' claims.

Glossary

  • Harness: the system around a model (prompts, tools, memory, orchestration) that lets it act as an agent.
  • Inference: running a trained model to get outputs.
  • Clean-room: written without copying the original program's code, by the authors' own description.
  • MCP: Model Context Protocol, a standard for connecting tools to AI agents.
