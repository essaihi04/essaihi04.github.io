unslop: setup guide

👉 Open the link⬇ Download the PDF

What it is: a skill for Claude Code and Codex that turns vibecoded, AI-looking UI into a designed interface. Created by Damir Sokolovsky (@heydamir). Licence: CC BY 4.0 (keep the credit).

Repo: https://github.com/heydamir/unslop

What it does

  • Finds the "tells" of AI-generated UI first: purple gradients, glows, emoji labels, shouty copy, uneven spacing.
  • Proposes a direction (product, character, world, moments, signature) and waits for your answer before editing.
  • Fixes the screen in nine passes, in order: spacing, color, icons, copy, type, layout, details, visuals, motion.
  • Works with React, Vue, Svelte, Tailwind or plain HTML/CSS, and can start from a live URL.

Install (Claude Code)

git clone https://github.com/heydamir/unslop
mkdir -p ~/.claude/skills && cp -r unslop/skills/unslop ~/.claude/skills/

For one project only, copy it into .claude/skills/ inside that project.

Optional (to snapshot a live site or make a story video): npm install -D playwright, npx playwright install chromium, plus ffmpeg on your PATH.

Use it

/unslop this dashboard
/unslop the hero of https://example.com

3 ways to use it

  1. Clean up a dashboard you built with an AI agent.
  2. Polish a landing page before you launch.
  3. Redesign a live page from just its link (it saves a copy to work on).

Our test

In a sandbox with no secrets, the clone and the copy into a skills folder took under one second. The skill folder holds SKILL.md (233 lines), reference files (signs of slop, tokens, visuals, effects) and two scripts (snapshot.mjs, story.mjs). We did not run the design passes themselves.
