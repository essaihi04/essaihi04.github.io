RapidOCR: free offline OCR in Python

👉 Open the link⬇ Download the PDF

What it is: RapidOCR (RapidAI/RapidOCR) turns images of text into text, on your own machine, using ONNX Runtime. No cloud service and no API key. Licence: Apache-2.0.

Install, step by step

  1. Create a virtual environment: python3 -m venv v
  2. Install the package: ./v/bin/pip install rapidocr_onnxruntime
  3. Run it on an image:
    4. from rapidocr_onnxruntime import RapidOCR
engine = RapidOCR()
result, _ = engine("invoice.png")
print([line[1] for line in result])

What we tested

  • Sandbox with an empty environment (no tokens, no keys).
  • One test image with two lines of text: "Invoice 2026-1105" and "Total: 249.90 USD".
  • Both lines were read correctly in 1.4 seconds on a plain CPU (after the install).

3 ways to use it

  • Pull the text out of scanned receipts and invoices, locally.
  • Make screenshots searchable.
  • Add an offline OCR step to a script, with no paid API.

Good to know

  • This is one small test, not a benchmark: try it on your own images.
  • Check the licence and README in the repository before using it in a project.
