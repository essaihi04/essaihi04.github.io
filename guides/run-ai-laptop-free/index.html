Run an AI Model on Your Laptop: Cheat Sheet

Everything from the Short, in one place. Facts from the Ollama README and model page (links at the end).

1. Install Ollama

Ollama is open source (MIT license) and runs on macOS, Windows and Linux.

  • macOS: curl -fsSL https://ollama.com/install.sh | sh, or download the Ollama.dmg installer.
  • Windows: irm https://ollama.com/install.ps1 | iex in PowerShell, or download OllamaSetup.exe.
  • Linux: curl -fsSL https://ollama.com/install.sh | sh

2. Run your first model

ollama run llama3.2

This pulls the default Llama 3.2 model (3B parameters, about 2.0 GB) the first time, then opens a chat in your terminal. Type a question and press Enter.

3. Short on space?

ollama run llama3.2:1b

The 1B version is about 1.3 GB.

Quick reference

  • ollama run <model>: chat with a model (downloads it if needed)
  • Both Llama 3.2 sizes list a 128K context length on the model page.
