What it does

PdfCraft is a PDF reader and editor written in pure Rust. Besides the desktop app it ships a command-line tool, pdfcraft-cli, that can combine, split, extract, rotate and delete pages, edit metadata, extract text and render pages to images. The project's README says it has no account and no telemetry.

Install, step by step

Building needs Rust 1.95 or later (the README says so).

  1. Clone the repo: git clone https://github.com/storytold/pdfcraft
  2. Go into it: cd pdfcraft
  3. Build only the command-line tool: cargo build --release -p pdfcraft-cli --no-default-features
  4. The binary is in target/release/pdfcraft-cli. In our test the build took about 7 minutes on a 4-core machine.
  5. Prefer the desktop app? The README shows cargo run --release -p pdfcraft -- some.pdf, and prebuilt releases are on the GitHub Releases page.

3 things to try (all tested in the video)

  1. Combine files: pdfcraft-cli combine invoice.pdf contract.pdf --out combined.pdf (2 files, 5 pages in our test)
  2. Pick pages: pdfcraft-cli extract combined.pdf --pages 1,3-4 --out picked.pdf
  3. Delete, rotate, retitle: pdfcraft-cli edit combined.pdf --out final.pdf --delete 2 --rotate 1:90 --title Signed

Good to know

  • Run pdfcraft-cli --help to see every command (info, render, text, split, check, audit, batch).
  • The project is about a month old and moves fast: check the README and the Releases page for the latest instructions.
  • Always keep a copy of your original PDFs before editing.
