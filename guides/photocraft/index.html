PhotoCraft: setup guide

👉 Open the link⬇ Download the PDF

What it is: an open-source image editor written in pure Rust. Per its README: layers, masks, adjustment layers, layer styles, type, vectors, brushes and PSD files, in a native app. Status: early alpha (README). License: MIT or Apache-2.0.

Link: https://github.com/storytold/photocraft

What we tested

  • Cloned the repo into a sandbox (no secrets in the environment).
  • Ran cargo test -p photocraft-psd (the PSD file crate): 222 unit/integration tests + 1 doctest passed, 0 failed, about 55 s from a cold clone, compile included.
  • We did not test the desktop app itself or the whole workspace.
  • Stars: 71,897 on 2026-10-23, about 3 weeks after creation (GitHub API).

Install (from the README)

  1. Install Rust: https://rustup.rs
  2. git clone https://github.com/storytold/photocraft && cd photocraft
  3. Run the app: cargo run --release -p photocraft -- image.psd
  4. Run the tests: cargo test --workspace
  5. Linux may need system libraries for the UI; check the README.

3 things to try

  1. Open a PSD you own and inspect its layer tree.
  2. Add a Curves adjustment layer and save in the native .pcraft format.
  3. Run the tests of one crate (cargo test -p photocraft-psd) and read how PSD round trips are checked.

Honest verdict

Impressive engineering and a lot of tests, but the README itself says early alpha: don't replace your main editor yet.

Sources: the repository README and Cargo files; GitHub API data (stars); our own sandbox test run.
