AliasVault: self-host your password manager

👉 Open the link⬇ Download the PDF

What it is: AliasVault is an open-source password and email alias manager. Passwords are end-to-end encrypted and it includes its own mail server. Repo: https://github.com/aliasvault/aliasvault (license: AGPL-3.0).

What we checked (in a sandbox, no secrets)

  • We cloned the repo and read the license: GNU AGPL v3.
  • docker-compose.yml lists 7 images: postgres, client, api, admin, reverse-proxy, smtp and task-runner.
  • We did not run the full stack in this test. Read the official docs before trusting it with real passwords.

Requirements (from the README)

1 vCPU, 1 GB RAM, 5 GB free disk (16 GB recommended), Docker 20.10 or newer, 64-bit Linux.

Install steps (README, "Install Script" method)

  1. curl -L -o install.sh https://github.com/aliasvault/aliasvault/releases/latest/download/install.sh
  2. chmod +x install.sh
  3. ./install.sh install

Read the script before running it. Full guide: https://docs.aliasvault.com/installation

3 things to do

  1. Try the cloud version first at https://app.aliasvault.com to see if you like it.
  2. Self-host on a small VPS or home server with Docker.
  3. Back up your data and keep the stack updated.

2 mistakes to avoid

  1. Running an install script without reading it.
  2. Exposing a self-hosted vault with no backup.
