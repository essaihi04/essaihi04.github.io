Which AI for Which Job? The test prompt

⬇ Download the PDF

A quick way to pick between ChatGPT, Claude and Gemini for *your* work, without trusting any ranking.

The test prompt (copy, paste, run on two assistants)

You are helping me with a real task from my work.
Task: [paste your real task: an email to rewrite, a bug to fix, or a long text to summarize]
Context: [who it is for, what tone, what format]
Give me one result, then list 2 things you were unsure about.

How to compare

  1. Run the same prompt on two assistants. All three have a free plan.
  2. Judge the result against what you would send or ship, not how impressive it sounds.
  3. Keep the one that needed the fewest edits. Repeat next month: these tools change often.

What each is documented to do well

| Job | Pick to try | Documented feature |

|---|---|---|

| Writing and editing | ChatGPT | Canvas: highlight a passage and ask for a change (OpenAI Help) |

| Coding | Claude | Claude Code, Anthropic's coding agent (docs) |

| Summarizing email and docs | Gemini | Built into Gmail, Docs, Sheets, Slides and Meet (TechRadar) |

This is not a ranking and not personal advice: features and plans change, so check each provider's page.
