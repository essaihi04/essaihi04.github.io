Setup steps for the five apps tested in the Repo Radar video (November 10, 2026). Every app was installed in an emptied sandbox, using only the commands from its own README. 1. Piper: text to speech on your own computer

Repo: OHF-Voice/piper1-gpl (GPL-3.0). The older repo rhasspy/piper is archived.

python3 -m venv .venv
.venv/bin/pip install piper-tts
.venv/bin/python -m piper.download_voices en_US-lessac-medium
echo 'Hello from Piper.' | .venv/bin/python -m piper -m en_US-lessac-medium -f hello.wav

Our run: install 10.5 s, voice download (63 MB) 1.7 s, first sentence 2.9 s. No graphics card needed.

2. faster-whisper: speech to text, offline

Repo: SYSTRAN/faster-whisper (MIT).

python3 -m venv .venv
.venv/bin/pip install faster-whisper

Then, in Python:

from faster_whisper import WhisperModel
model = WhisperModel("tiny.en", device="cpu", compute_type="int8")
segments, info = model.transcribe("audio.mp3")
for s in segments:
    print(f"[{s.start:.1f}s -> {s.end:.1f}s] {s.text}")

Our run: install 18.9 s; 11 s of audio transcribed in 2.4 s on a CPU, model download included. Use a bigger model (small, medium) for better accuracy.

3. rembg: background removal

Repo: danielgatis/rembg (MIT).

python3 -m venv .venv
.venv/bin/pip install "rembg[cpu,cli]"
.venv/bin/rembg i input.jpg output.png

Our run: install 48.1 s; the first image took 89 s because the default model (1.02 GB) downloads once. Batch a whole folder with rembg p input_folder output_folder.

4. Actual Budget: envelope budgeting

Repo: actualbudget/actual (MIT).

mkdir actual && cd actual
npm init -y
npm install @actual-app/sync-server
npx actual-server

Then open http://localhost:5006 in your browser. Our run: install 11.9 s, server started and listened on port 5006. Our sandbox refused local connections, so we could not open the page inside it. Docker images are also documented in the README.

5. Stirling PDF: 50+ PDF tools you host yourself

Repo: Stirling-Tools/Stirling-PDF. Core under MIT; some folders (for example app/proprietary/) have their own license.

The simplest route from the README:

docker run -p 8080:8080 docker.stirlingpdf.com/stirlingtools/stirling-pdf

Then open http://localhost:8080. Building from source (./gradlew bootJar) took 2 min 38 s in our sandbox. The jar needs Java 25: on Java 21 it stops with UnsupportedClassVersionError.

What you take on when you self-host

  • Updates: nobody pushes them to you. Pull new versions yourself.
  • Backups: if your data lives on your server, back up that server.
  • Support: no help desk. Use the GitHub issues page of each repo.
