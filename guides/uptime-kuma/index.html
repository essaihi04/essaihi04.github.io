Uptime Kuma: setup steps

👉 Open the link⬇ Download the PDF

What it is: a free, self-hosted monitoring tool. It checks your websites, ping, DNS records and Docker containers, and alerts you when something goes down.

Licence: MIT. Repo: https://github.com/louislam/uptime-kuma

Install with Docker (easiest)

mkdir uptime-kuma
cd uptime-kuma
curl -o compose.yaml https://raw.githubusercontent.com/louislam/uptime-kuma/master/compose.yaml
docker compose up -d

Then open http://localhost:3001 and create your admin account.

What I tested (sandbox, no secrets)

  • Version 2.5.9, Node 22: npm ci took about 62 seconds, npm run build about 18 seconds, then node server/server.js started and served the setup page.
  • The 3.0 beta (3.0.0-beta.0) refused to start on Node 22: it requires Node 26.2 or newer. Use the stable 2.x line unless you run Node 26.

3 things to do

  1. Add your main website as an HTTP(s) monitor.
  2. Add a notification channel (Telegram, Discord or Slack).
  3. Create a status page and share it with your users.

2 mistakes to avoid

  • Do not store the data folder on NFS: it is not supported.
  • Do not run the 3.0 beta in production on an older Node version.

Source: project README (features, 20-second intervals, 90+ notification services).
