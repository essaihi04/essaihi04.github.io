Memos: self-host your own notes

👉 Open the link⬇ Download the PDF

What it is. Memos is an open-source, self-hosted note-taking app. Notes are written in Markdown and kept on a personal timeline, with tags to connect related thoughts. Your data stays on your own server. You choose what stays private, what is shared and what is published.

License: MIT. Repo: https://github.com/usememos/memos

Install in one command (Docker)

docker run -d \
  --name memos \
  -p 5230:5230 \
  -v ~/.memos:/var/opt/memos \
  neosmemo/memos:stable

Open http://localhost:5230 and create the first account. Everything Memos keeps is in ~/.memos, so back up that one folder.

What we tested

We built the server from source in a sandbox (about 110 seconds with Go), started it, and the health check at /healthz answered HTTP 200. We did not test the Docker image itself.

3 ways to use it

  1. A quick daily journal: one sentence is a whole memo.
  2. Tag-based project notes you can find again later.
  3. Save web pages as Markdown with the Web Clipper (Chrome and Firefox), or connect scripts and AI tools through the API and MCP server.
