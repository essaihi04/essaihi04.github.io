What it is

Trilium Notes is a free, open-source, cross-platform hierarchical note-taking application focused on building large personal knowledge bases (from the project README).

Install (what we ran)

  1. git clone --depth 1 https://github.com/TriliumNext/Trilium.git
  2. cd Trilium && pnpm install --frozen-lockfile

In our sandbox test the dependency install finished with no errors in about 20 seconds (pnpm reported "Done in 19.8s"). We did not launch the full app in the sandbox. For everyday use, the project documents ready-made downloads and a Docker setup: https://docs.triliumnotes.org/

3 ways to use it

  • A personal knowledge base: notes nested inside notes, in one tree.
  • A daily journal alongside your project notes.
  • A self-hosted notes server where your data stays on your machine.

Honest verdict

Setup is easy, but it is not a Notion clone: it is built for deep personal notes, not team dashboards.
