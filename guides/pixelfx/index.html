pixelfx: setup guide

👉 Open the link⬇ Download the PDF

What it is: a free, MIT-licensed JavaScript library of 244 pixel art effects (fire, explosions, lightning, ice, UI, pickups and more). Every effect is a small piece of code. Repo: https://github.com/patch-gg/pixelfx

Install (Node 18 or newer)

  1. In your game project: npm i github:patch-gg/pixelfx
  2. Or clone the repo and run npm install, then render an effect to a sprite sheet:

node tools/render.mjs fire/campfire --sheet

  1. Try another: node tools/render.mjs ice/frost-nova --sheet

What we measured in a sandbox (no GPU, empty environment)

  • npm install: about 1 second.
  • fire/campfire: 90 frames rendered in about 1.4 s.
  • ice/frost-nova: 103 frames rendered in about 2.7 s.
  • Each run wrote a transparent sprite sheet PNG, a contact sheet and an Aseprite-style JSON file.

3 ways to use it

  1. Browser game (canvas, Phaser, PixiJS): import createFrame, createFx and composite from the library, then draw each effect on your canvas.
  2. Any engine (Godot, Unity, GameMaker...): export sprite sheets with tools/render.mjs; the JSON works with Aseprite importers.
  3. Recolor it: pass a palette option (dark-to-bright hex ramp) so a fire can burn blue.
