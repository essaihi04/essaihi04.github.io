DeepSeek Harness (dsh): setup guide

👉 Open the link⬇ Download the PDF

DeepSeek Harness is DeepSeek's open-source agent harness (MIT license). Its idea: everything is a plugin. The model, the tools, the sandbox, the scheduler and even the web interface are separate packages you can swap. Tested by Repo Radar in a sandbox on 2026-11-17 (version 0.2.2-rc.3).

Key facts (checked 2026-11-17)

  • 282,655 GitHub stars, created 2026-08-13 (GitHub API).
  • License: MIT.
  • Status: developer preview. The README warns: "THERE WILL BE COMPATIBILITY-BREAKING CHANGES."
  • packages/ holds 53 plugin families: llm, shell, sandbox, web, mcp, skill, subagent, browser-use, schedule, team, terminal and more.

Read this first

  • Read SAFETY.md. An agent can run commands: wrong model output or an untrusted plugin may modify or delete files. Start in a throwaway folder or a VM.
  • The harness is free. The default model (DeepSeek) needs a DeepSeek API key, billed per use by DeepSeek. Without it, our run stopped with MISSING_CREDENTIAL: llm-deepseek.

Option 1: run from npm (fastest)

  1. Install Node.js (the repo asks for Node 24.9 or newer).
  2. Run:
    3. npx @deepseek-ai/dsh web
  3. The web UI opens at http://127.0.0.1:3080. The link printed in the terminal contains a secret token: without it the server answers 401. Don't share that link.
  4. Add your DeepSeek API key on the Models page (or export DEEPSEEK_API_KEY before launching).

Option 2: build from source (what we did)

git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness
pnpm install
pnpm run build
pnpm dsh web
  • Our build: 10 checks passed, 0 failed, in about 4.5 to 5 minutes on 4 CPUs.

3 things to try

  1. One-shot task from the terminal: dsh headless "run the tests" answers one task, prints the result and exits.
  2. Terminal UI: dsh tui (resume a session with dsh tui --resume <session>).
  3. Install a plugin: dsh plugin --profile tui add <package>. Community plugins use the GitHub topic dsh-plugin.

Useful flags

  • --no-open: start the web server without opening a browser.
  • --dump-config: print the composed profile (which plugins are loaded) and exit.
  • --patch <file.yml>: add an extra config layer on top of a profile.
