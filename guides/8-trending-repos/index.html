Every repo below was tested on November 5 to 6, 2026, inside a locked sandbox: a fresh temporary folder, an emptied environment (no tokens, no keys), a time limit on every command. Only commands documented by each README were run. Stars are from the GitHub API snapshot of November 5, 2026.

The scorecard

  1. obra/superpowers (MIT, 312,566 stars). Contents verified: 15 skills. The official install is a Claude Code plugin command, which could not be run in the sandbox.
  2. mattpocock/skills (MIT, 313,670 stars). npm install took 4.7 s, clean. 39 skill files counted.
  3. heydamir/unslop (CC-BY-4.0, 8,883 stars). The skill folder was copied clean. Snapshots and story videos need Playwright and ffmpeg: not tested.
  4. caru-ini/stack-diagram (MIT, 1,782 stars). Installed in 6.7 s. Diagram generation not tested.

The commands, repo by repo

pixelfx (Node 18+)

git clone https://github.com/patch-gg/pixelfx.git
cd pixelfx
npm install
node tools/render.mjs fire/campfire --sheet

Writes a contact sheet, a sprite sheet and a JSON file for the campfire effect.

graphify (Python 3.10+)

python3 -m venv v
v/bin/pip install .
v/bin/graphify update .

Builds graphify-out/graph.json, graph.html and GRAPH_REPORT.md from code, locally, with no AI. The README's own recommended install is uv tool install graphifyy.

mattpocock/skills

git clone https://github.com/mattpocock/skills.git
cd skills
npm install
find skills -name SKILL.md | wc -l

stack-diagram and anatomy (skills CLI)

npx skills add caru-ini/stack-diagram -a claude-code
npx skills add wheresryan22/anatomy -g -a claude-code

unslop

Copy the folder skills/unslop into your agent's skills directory. For snapshots and story videos, install Playwright and ffmpeg first, as its README says.

DeepInfer

Do not expect this one to run on a laptop. Its README asks for Linux, GCC 13 or newer, Python 3.12, CUDA 13, and lists only NVIDIA SM100 GPUs or Huawei Ascend 950 NPUs as supported hardware.

3 things to do

  1. Run a repo's own documented command for 60 seconds before you read about it for an hour.
  2. Check the license before you build on it. unslop is CC-BY-4.0, a content license, not MIT.
  3. Check the Python and Node versions in the README first. It would have saved me one failure.

2 mistakes to avoid

  1. Treating stars as proof that something runs.
  2. Treating "installed" as "works": a skill you can install is not a skill you have tried.

Glossary

  • Skill: a folder with a text file of instructions that an AI coding assistant loads when the task fits.
  • Sandbox: a throwaway folder and an emptied environment, so a repo you test cannot see your keys.
  • Sprite sheet: one image holding every frame of an animation, used by game engines.
  • Knowledge graph: nodes (functions, files) and edges (calls, imports) you can query.
