Graphify: map any codebase into a queryable graph

👉 Open the link⬇ Download the PDF

What it is. Graphify (Graphify-Labs/graphify) is an open-source skill and CLI that turns a project (code, docs, PDFs, configs) into a knowledge graph you can query instead of grepping. It is not a vector index: no embeddings, no vector store.

License: Apache-2.0. About 142,000 GitHub stars on 2026-11-05 (source: GitHub API snapshot).

Install (from the README)

Needs Python 3.10+ and uv (or pipx).

uv tool install graphifyy      # or: pipx install graphifyy

Note the double "y" in the package name: graphifyy.

Then, in Claude Code, Cursor, Codex or Gemini CLI, type /graphify in your project.

What we measured (sandbox test, 2026-11-05)

  • Command: graphify extract graphify --code-only on the repo's own graphify/ folder
  • 99 code files, 4,113 nodes, 9,380 edges, 190 communities
  • About 10.6 seconds, no API key (code-only mode uses local AST parsing)

3 ways to use it

  1. Map an unfamiliar repo before reading it.
  2. Ask how two parts of a codebase connect, then trace the path.
  3. Export the graph (graphify export html) to explore it visually.
