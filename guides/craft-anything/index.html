What it does

Craft Anything studies a website, app, game or file with real inspection tools, has a coding agent build your own version, then compares the build with the original and lists what does not match yet. It works in four steps: Study → Build → Check → Ready. It is written in Rust and ships a desktop app, a CLI and an MCP server ("320 tools, each one a CLI command and an MCP tool", per the README).

What we tested (Repo Radar sandbox, 2026-11-16)

  • cargo build -p craft-anything-cli: compiled in 6 min 05 s on 4 cores.
  • craft-anything-cli doctor: healthy; the built-in MCP server answered its self-test.
  • craft-anything-cli triage /bin/ls: refused by default. Clean room mode never reads inside the original.
  • craft-anything-cli --deep triage /bin/ls: "ls is a program for Linux, built for x86_64 (64-bit). Its internal names were removed (stripped)", plus its 2 libraries and entry point.
  • Not tested: a full rebuild. It needs a coding agent signed in (Claude Code is the builder that works today, per the README).

Install

  1. Install Rust 1.97 or newer (rustup update).
  2. Clone the repo:
    3. git clone https://github.com/storytold/craft-anything
cd craft-anything
  3. Desktop app: cargo run --release -p craft-anything

(on Debian/Ubuntu the README lists extra system packages for the window toolkit).

  1. CLI: cargo install --path apps/craft-anything-cli
  2. Check the install: craft-anything-cli doctor

Prebuilt installers for Windows, macOS, Linux and FreeBSD are on the repo's Releases page (still alpha).

3 ways to use it

  1. Look inside a program, no AI needed: craft-anything-cli --deep triage <file> gives a plain-English summary, then suggests next tools (native-functions-list, native-strings-find…). craft-anything-cli commands lists every tool.
  2. Rebuild a website or a game: craft-anything-cli rebuild https://example.com "Recreate this website" or craft-anything-cli rebuild - "A snake game in Rust" --rounds 1.
  3. Give its tools to your agent: craft-anything-cli mcp serves them to any MCP client; craft-anything-cli setup connects coding-agent apps.

Use it responsibly

  • Only on software you own or are allowed to examine. The project says it never bypasses DRM, logins or anti-cheat.
  • Clean room (default) works only from what you can see; Deep mode reads code and files "for your private use".
  • Installing a generated project's dependencies runs code: approve commands only for projects you trust.
  • Generated pictures and 3D models are opt-in and paid with your own fal.ai key; everything else works without it.
