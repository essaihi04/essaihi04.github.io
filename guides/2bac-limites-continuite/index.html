Limites et continuité : résumé

Mathématiques · 2BAC Sciences Physiques BIOF · Chapitre 1

1. La limite, une tendance

La limite décrit le comportement de f(x) quand x s'approche d'une valeur a, ou quand x tend vers +∞ ou −∞. Approcher n'est pas atteindre.
  • Limites usuelles : lim (x→+∞) 1/x = 0 ; lim (x→0⁺) 1/x = +∞ ; lim (x→+∞) √x = +∞.
  • En un point a : si la limite à gauche et la limite à droite sont égales à ℓ, alors lim (x→a) f(x) = ℓ.

2. Formes indéterminées

  • Formes : 0/0, ∞/∞, ∞ − ∞, 0 × ∞. Elles imposent de transformer l'expression.
  • Polynôme ou fraction : factoriser (ou garder le terme de plus haut degré en ±∞).
  • Racine carrée : multiplier par le conjugué.

3. Asymptotes et continuité

  • lim (x→a) f(x) = ±∞ : asymptote verticale x = a. lim (x→±∞) f(x) = b : asymptote horizontale y = b.
  • lim (x→±∞) [f(x) − (ax + b)] = 0 : asymptote oblique y = ax + b.
    • f est continue en a si lim (x→a) f(x) = f(a).
    TVI : si f est continue sur [a, b] et f(a) × f(b) < 0, l'équation f(x) = 0 a au moins une solution dans ]a, b[ ; une seule si f est strictement monotone.

4. Mini-exercice

Calculer lim (x→2) (x² − 4)/(x − 2), puis lim (x→+∞) (2x² + 1)/(x² − 3).

Correction : forme 0/0 ; on factorise : (x − 2)(x + 2)/(x − 2) = x + 2, donc la limite vaut 4.

En +∞ on garde les termes de plus haut degré : 2x²/x² = 2, donc la limite vaut 2 (asymptote horizontale y = 2).
