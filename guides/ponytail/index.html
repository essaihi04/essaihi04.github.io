Ponytail: setup guide

👉 Open the link⬇ Download the PDF

What it is: a free, MIT-licensed prompt (a 52-line SKILL.md) that makes your AI coding agent pick the smallest change that solves the task.

Before writing code, the agent works down a ladder: does it need to exist, is it already in the codebase, does the standard library or the browser do it, is there an installed dependency, can it be one line, and only then the minimum that works.

Link: https://github.com/DietrichGebert/ponytail

Install in Claude Code

Send these as two separate prompts:

/plugin marketplace add DietrichGebert/ponytail
/plugin install ponytail@ponytail

Other agents: copy AGENTS.md into your project, or install skills/ponytail/SKILL.md as a skill (see INSTALL.md in the repo). The hooks need node on your PATH.

Commands (from the README)

  • /ponytail [lite | full | ultra | off]: set the intensity
  • /ponytail-review: review the current diff
  • /ponytail-audit: the same check for the whole repo
  • /ponytail-debt: collect deferred shortcut: comments

3 ways to use it

  1. Ask for a small UI feature and watch it reuse your existing components or native browser features.
  2. Run /ponytail-review on a diff before you merge.
  3. Run /ponytail-audit on an old repo to find code you can cut.

What we measured

Cloned into a sandbox on 2026-10-29: skills/ponytail/SKILL.md is 52 lines; the repo's own test suite ran 144 tests, 143 passed and 1 failed.

The "335 lines down to 10" date picker is the README's own example, not our benchmark.
