Kiri: the Docker Desktop alternative with a built-in public tunnel

👉 Open the link⬇ Download the PDF

Repo: libracoder/kiri · Apache-2.0 · Rust · macOS, Windows, Linux · free, in beta (runkiri.com, November 2026).

What it is

  • A lightweight replacement for Docker Desktop and OrbStack. It speaks the Docker Engine API, so docker, Compose and buildx keep working.
  • On macOS and Windows it runs containers in one small Linux VM; on Linux it runs straight on the kernel.
  • Kiri Share: one command gives a local port or a container a public HTTPS address on runkiri.cloud (an ngrok-style tunnel).

What we measured (Repo Radar sandbox, 18 Nov 2026)

  • cargo build -p kiri -p kiri-init (debug build): 29.11 s on a cloud VM.
  • docker version against Kiri's socket answers Server: Kiri, API 1.47, written in Rust.
  • Daemon memory: 14,156 KB (about 14 MB). The README says "about 15 MB".
  • kiri share 8000 answered "not signed in": the tunnel needs a sign-in first (GitHub device flow, kiri share login).
  • Containers did not start in our locked cloud sandbox ("the agent exited"), so we could not check the speed claim.
  • Speed claim from the README (their benchmark, median of 30 runs): Kiri 2.55 ms, Docker Desktop 213 ms, OrbStack 380 ms per docker run through the Engine API.

Install

  1. Download the installer from runkiri.com/releases: .dmg (macOS 14+), .msi (Windows 10/11 via WSL 2), .deb or .rpm (Linux).
  2. Open Kiri once: it creates a kiri Docker context.
  3. Test it:
    4. docker --context kiri run --rm alpine echo hello

3 ways to use it

  1. Share a local app on the internet
    2. kiri share login        # one time, with GitHub
kiri 3000               # port 3000 at a random https://….runkiri.cloud address
kiri 3000 myapp         # myapp.runkiri.cloud, once the name is reserved and approved

The first visit to a share shows a Kiri warning page before it opens.

  1. Replace Docker Desktop for Compose projects
    2. docker --context kiri compose up -d
kiri import             # bring images, volumes and containers over from OrbStack or Docker Desktop
  2. A one-command Kubernetes cluster or Linux machine
    3. kiri k8s start
kiri machine create dev --distro ubuntu && kiri machine shell dev

Good to know

  • Still in beta: expect changes. Read the release notes in docs/releases before upgrading.
  • The tunnel runs through Kiri's own cloud (runkiri.cloud): don't expose anything private without your own authentication.
  • Compare with ngrok's free plan (ngrok.com/pricing, Nov 2026): 1 GB of data transfer out and 3 endpoints, paid plans from $8/month.
