Sync-in: self-hosted file sync, quick guide

👉 Open the link⬇ Download the PDF

What it is: Sync-in is an open-source (AGPL-3.0) self-hosted platform for file storage, synchronization and team collaboration. Files stay readable on your own filesystem.

Source: https://github.com/Sync-in/server (README)

What it offers (from the README)

  • Web interface, sharing links with passwords and expiry dates
  • WebDAV support, so file explorers can mount it like a network drive
  • Interface in more than 50 languages
  • Desktop and CLI clients for Windows, macOS and Linux: https://github.com/Sync-in/desktop

Setup

The project documents two routes: Docker (https://sync-in.com/docs/setup-guide/docker) and npm (https://sync-in.com/docs/setup-guide/npm).

Its backend uses a MySQL-compatible database (mysql2 driver in backend/package.json), so plan for one.

What we tested

In a throwaway sandbox on 2026-11-06 we cloned the repo and ran npm ci --ignore-scripts: 1,332 packages installed in about 22 seconds (Node 22).

We did NOT run a full server with a database, so we make no claim about runtime behaviour.

3 uses

  1. Replace a paid cloud-storage plan with your own server.
  2. Share files with a link that expires.
  3. Mount a remote folder as a network drive through WebDAV.

Always read the licence and the docs yourself before exposing a server to the internet.
